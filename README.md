**ExplorerBlurMica** - это DLL-библиотека для Windows, которая модифицирует внешний вид проводника Windows (Explorer), добавляя эффекты размытия (blur) и Mica-материала. Проект использует технику API-хукинга для перехвата и модификации функций отрисовки DirectUI.

## 🚀 Быстрый старт

### Установка и включение

1. **Скачайте проект** и распакуйте в удобную папку
2. **Запустите `src/register.cmd`** с правами администратора
   - Скрипт автоматически запросит права администратора
   - Дождитесь завершения установки
   - Окно закроется автоматически через 5 секунд

### Отключение и удаление

1. **Запустите `src/uninstall.cmd`** с правами администратора
2. **Дождитесь завершения** процесса удаления
3. **Explorer перезапустится** автоматически

### Настройка эффектов

Отредактируйте файл `src/config.ini`:

```ini
[config]
effect=0              # Тип эффекта: 0-3
clearAddress=false    # Очистить адресную строку
clearBarBg=false      # Очистить фон панелей
clearWinUIBg=false    # Очистить WinUI фон
showLine=false        # Показать линии

[light]               # Цвета для светлой темы
r=255
g=255
b=255
a=255

[dark]                # Цвета для темной темы
r=255
g=255
b=255
a=255
```

**После изменения конфигурации перезапустите Explorer** для применения настроек.

### Типы эффектов

- **0** - Без эффектов (отключено)
- **1** - Размытие (Blur)
- **2** - Mica материал
- **3** - Комбинированный эффект

### Важные замечания

- ⚠️ **Требуются права администратора** для установки/удаления
- 🔄 **Explorer перезапускается** автоматически при установке
- 📁 **Работает только с Windows Explorer** (проводник файлов)
- 🎨 **Эффекты применяются** к панелям навигации и адресной строке

## 2. Описание файлов

### Основные файлы

#### `dllmain.cpp`
- **Назначение**: Точка входа DLL-библиотеки
- **Ключевые функции**: `DllMain()` - обработчик событий загрузки/выгрузки DLL
- **Связи**: Вызывает `MBox::OnDllMain()` из `module.h`
- **Логика**: Инициализация и очистка при загрузке/выгрузке библиотеки

#### `module.h`
- **Назначение**: Основной модуль проекта
- **Ключевые элементы**: 
  - `CLSID_FolderExtension` - идентификатор расширения
  - `regPath` - путь в реестре для регистрации
- **Связи**: Используется в `dllmain.cpp`
- **Логика**: Определяет константы и основную функцию инициализации

#### `framework.h`
- **Назначение**: Основные включения и настройки
- **Ключевые элементы**: Включения Windows API, COM, DirectUI
- **Связи**: Включается во всех основных файлах
- **Логика**: Централизованное управление зависимостями

### Система хукинга

#### `HookDef.h`
- **Назначение**: Определения всех API-хуков
- **Ключевые функции**:
  - `My_DirectUI_Element_PaintBackground()` - хук отрисовки фона
  - `My_DwmExtendFrameIntoClientArea()` - хук DWM
  - `My_CreateWindowExW_*()` - хуки создания окон
- **Связи**: Использует `DirectUITweaker.h` и `minhook`
- **Логика**: Перехват и модификация функций отрисовки

#### `DirectUITweaker.h`
- **Назначение**: Модификатор DirectUI элементов
- **Ключевые классы**:
  - `BlinkEraserListener` - удаление мерцания
  - `CabinetWClassListener` - обработка главного окна
  - `BlackDesktopChildSiteBridgeListener` - обработка дочерних окон
- **Связи**: Использует `WindowListener.h`
- **Логика**: Применение эффектов к DirectUI элементам

### Система слушателей

#### `WindowListener.h`
- **Назначение**: Система подписки на события окон
- **Ключевые классы**:
  - `IWindowListenerCallback` - интерфейс обратного вызова
  - `WindowListenerImpl` - базовая реализация
  - `WindowListener` - управление списком окон
- **Связи**: Используется в `DirectUITweaker.h`
- **Логика**: Подписка на сообщения окон и их обработка

### Вспомогательные модули

#### `Helper/Win32Helper.h`
- **Назначение**: Утилиты для работы с Win32 API
- **Ключевые функции**:
  - `scope_exit()` - RAII для автоматической очистки
  - `GetChildByClass()` - поиск дочерних окон
  - `get_module_name()` - получение имени модуля
- **Связи**: Используется во всех модулях
- **Логика**: Упрощение работы с Windows API

#### `Helper/VersionHelper.h`
- **Назначение**: Определение версии Windows
- **Ключевые структуры**:
  - `KUSER_SHARED_DATA` - системная информация
  - `KSYSTEM_TIME` - системное время
- **Связи**: Используется в `Win32Helper.h`
- **Логика**: Получение информации о системе

### Библиотека MinHook

#### `minhook/MinHook.h`
- **Назначение**: Главный заголовок библиотеки хукинга
- **Ключевые элементы**:
  - `MH_STATUS` - коды ошибок
  - `MH_THREAD_FREEZE_METHOD` - методы заморозки потоков
- **Связи**: Используется в `HookDef.h`
- **Логика**: Управление процессом хукинга

### Конфигурация и установка

#### `src/config.ini`
- **Назначение**: Конфигурационный файл
- **Ключевые параметры**:
  - `effect` - тип эффекта (0-3)
  - `clearAddress` - очистка адресной строки
  - `clearBarBg` - очистка фона панелей
  - `showLine` - показ линий
- **Связи**: Читается при инициализации
- **Логика**: Настройка поведения модификаций

#### `src/register.cmd`
- **Назначение**: Скрипт установки
- **Ключевые операции**:
  - Запрос прав администратора
  - Регистрация DLL через `regsvr32`
  - Перезапуск Explorer
- **Связи**: Регистрирует `ExplorerBlurMica.dll`
- **Логика**: Автоматическая установка в систему

## 4. Точка входа и запуск

### Процесс запуска

1. **Загрузка DLL**: Windows загружает `ExplorerBlurMica.dll` в процесс Explorer
2. **Инициализация**: Вызывается `DllMain()` с `DLL_PROCESS_ATTACH`
3. **Чтение конфигурации**: Загружается `config.ini`
4. **Установка хуков**: Инициализируется система MinHook
5. **Регистрация обработчиков**: Подписываются на события окон

### Ключевые функции инициализации

```cpp
// dllmain.cpp
BOOL APIENTRY DllMain(HMODULE hModule, DWORD ul_reason_for_call, LPVOID lpReserved)
{
    return MBox::OnDllMain(hModule, ul_reason_for_call);
}
```

### Установка в систему

1. Запуск `register.cmd` с правами администратора
2. Регистрация DLL через `regsvr32`
3. Перезапуск Explorer
4. Автоматическая загрузка при запуске Explorer

## 5. Архитектурные особенности

### Нестандартные решения

1. **API-хукинг вместо подклассирования**: Использование MinHook для перехвата функций на уровне API
2. **Система слушателей окон**: Гибкая архитектура для обработки событий окон
3. **RAII-паттерны**: Автоматическое управление ресурсами через `scope_exit()`
4. **Модульная структура**: Разделение на независимые модули с четкими интерфейсами

### Причины выбора архитектуры

1. **Производительность**: API-хукинг более эффективен чем подклассирование
2. **Надежность**: RAII-паттерны предотвращают утечки памяти
3. **Гибкость**: Система слушателей позволяет легко добавлять новые обработчики
4. **Совместимость**: Поддержка различных версий Windows через `VersionHelper`

### Технические особенности

- **Поддержка x86/x64**: Кроссплатформенная компиляция
- **Windows 10+**: Использование современных API
- **DirectUI интеграция**: Глубокая интеграция с системой отрисовки
- **Конфигурируемость**: Гибкая настройка через INI-файл
